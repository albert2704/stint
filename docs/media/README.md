# Stint images and video

These media assets show Stint with synthetic data from Flutter widget tests. They contain no personal desktop content or real session history.

| File | Description |
| --- | --- |
| `stint-overview.png` | 1280×720 README hero: actual dark timer, Stint branding, and the focus/rest/repeat message. |
| `demo.mp4` | 30-second feature overview of the 0.2.0 blocker beta, with the original Quiet Keys music bed at 1280×720 and 30 fps. |
| `demo.gif` | Smaller 800×450 looping version for inline README playback. |
| `stint-dark.png` | Timer and sound controls in dark appearance. |
| `stint-light.png` | Timer and sound controls in light appearance. |
| `stint-settings.png` | Adjustable focus/break durations and saved rhythms. |
| `stint-blocker.png` | 720×720 capture of the real Block distractions widget, with synthetic Chat and youtube.com selections and an active focus guard. |
| `progress-dark.png` | Synthetic daily goals, weekly totals, streaks, and completed stints. |
| `progress-light.png` | The same progress surface in light appearance. |

The animated overview uses a filling timer/cycle accent, moving callouts, a waveform, screenshot pushes, focus/pause chips, progress marks, and feature transitions. These illustrations stay outside the unmodified app captures. It moves through six scenes: focus, rhythms, music, distraction blocking, progress, and the Mac beta download. It is a designed feature overview using genuine app screenshots, not a live interaction recording. The music screenshot leaves “Play with timer” off while the accompanying copy explains enabling it.

Editable source and regeneration instructions are in [`tooling/video`](../../tooling/video/README.md). Timer and progress captures are generated by `test/pomodoro_ui_test.dart` and `test/progress_test.dart`. The blocker capture comes from `tooling/video/capture/capture_blocker_test.dart`, which supplies synthetic data without operating the native helper or changing network settings. Original Stint media is MIT licensed; bundled fonts and rendering dependencies keep their own licenses as documented in the source directory.

### Distraction blocker beta

<img src="stint-blocker.png" width="480" alt="Actual Stint blocker settings with synthetic Chat and youtube.com selections, Block during focus enabled, and Focus guard on">

The capture demonstrates an active focus guard using fixture data. It is not a live browser test. Selected apps hide while their documents stay open; website blocking requires administrator setup and a browser using macOS proxy settings. Pausing releases blocking. See [setup, supported behavior and limits](../blocking.md).

## Music

The MP4 includes the first 30 seconds of Stint’s original **Quiet Keys** track at 70% amplitude, with a 0.8-second fade-in and a 1.3-second fade-out from 28.7 to 30 seconds. Its source is frozen in the editable video project. This is original synthesized music distributed with Stint under MIT, not a third-party recording. The looping GIF has no audio.
