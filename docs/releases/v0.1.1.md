# Stint v0.1.1

_Released 10 October 2026 as a prerelease._

Stint 0.1.1 gives the app a consistent Stint identity throughout its code, saved data, and macOS integration. It starts fresh when replacing 0.1.0; your previous data is left untouched and is not imported automatically.

## Highlights

- **A complete Stint identity:** The app, executable, native components, preferences, and data folder now use Stint names.
- **A separate local workspace:** New timer settings, progress, music sources, and shortcuts belong to the new application identity.
- **The same focus workflow:** The menu bar timer, adjustable rhythms, music, completion alerts, Progress, and configurable shortcuts remain part of the app.

## Improvements

- The Dart package and native method channels now use `stint` consistently.
- Both macOS hosts, packaging scripts, tests, and public documentation refer to the new identity.
- The workspace JSON format remains version 1, including compatibility for its existing record types. This does not migrate a previous installation's workspace.

## Fixes

Removed outdated internal naming from the current app identity and public development instructions. Local analysis, all 146 Flutter tests, and 835 native checks pass, along with [CI checks](https://github.com/albert2704/stint/actions/runs/38021166305) and the [universal package workflow](https://github.com/albert2704/stint/actions/runs/38021166173). See [testing](../testing.md) for the scope and remaining limits.

## Breaking changes

**Version 0.1.1 starts with fresh settings, history, music library, and permissions.** It uses bundle identifier `io.github.albert2704.stint`, a `Stint` Application Support folder, and Stint preference keys.

Your previous timer and history, custom rhythms, imported music, saved YouTube links, volume and music preferences, alert choices, appearance, daily goal, and keyboard shortcuts do not carry over. macOS notification permission belongs to the new app identity and may need to be granted again.

The previous saved data is not deleted or modified. Version 0.1.1 does not read it and provides no automatic import or migration action. The new app's recovery button restores only its own previous save.

## Upgrade notes

Choose **Stint → Quit Stint** in the older app before replacing it or opening the new version. Closing its window is insufficient because the menu bar timer stays running. After opening 0.1.1, select your rhythm, add your music sources again, set any custom shortcuts, and allow notifications when prompted.

The target remains macOS 12 or later, with a universal package for Apple Silicon and Intel:

- [Download the DMG](https://github.com/albert2704/stint/releases/download/v0.1.1/Stint-0.1.1-macos-universal.dmg).
- [Download the ZIP](https://github.com/albert2704/stint/releases/download/v0.1.1/Stint-0.1.1-macos-universal.zip).
- [Download the checksums](https://github.com/albert2704/stint/releases/download/v0.1.1/SHA256SUMS.txt).

The preview uses an ad hoc signature, without Apple Developer ID signing or notarization. See the [installation guide](../install.md) for Gatekeeper guidance. Physical Intel and macOS 12 testing, the downloaded app's Gatekeeper flow, and a manual upgrade remain unverified. Android is not included.
